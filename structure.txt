2. DETAILED BACKEND ARCHITECTURE (app/)
------------------------------------------------------------------------

The backend is built as a modular Model-View-Controller (MVC) style Flask 
web application featuring dedicated blueprint packages and custom routing models.

* App Initialization (app/__init__.py):
  Configures logging, reads environment keys from .env (SMTP configurations, 
  Groq API credentials), registers Flask blueprints, and initializes core models:
  - Whisper ("base" speech transcription model loaded on start)
  - VADER Sentiment (for scoring candidate speech emotional tones)
  - MediaPipe configurations (configured landmark indices 33, 133, 159, 145 
    for blink tracking/EAR).

* Core ML Engine (app/analysis.py):
  Handles complex ML evaluation routines:
  - Transcribing recording audio streams using OpenAI Whisper.
  - Analyzing sentiment tones utilizing VADER Sentiment Analyzer.
  - Executing real-time or post-interview facial feedback metrics (blink tracking 
    and direct focus calculations using MediaPipe FaceMesh).
  - Calling Google Gemini API (via Groq/Google Generative AI clients with key rotation) 
    to evaluate responses against Key Expected Points, assigning structured score metrics.

* Business Logic & DAL (app/repositories/ & app/services/):
  Adheres to the repository pattern for clean separation of database concerns:
  - interviews_repo.py, reports_repo.py, users_repo.py manage clean parameter passing 
    to the SQLite connection pool (defined in db.py).
  - interview_service.py dictates high-level logic rules (e.g. checking whether 
    an interview invitation key is single-use, evaluating session validity).

* Email Notification System (app/email.py):
  Leverages Flask-Mail to coordinate outbound notifications:
  - Instantly broadcasts generated 2-Factor OTPs to candidates and recruiter registers.
  - Distributes secure, automated PDF report summaries directly to recruiters.


------------------------------------------------------------------------
3. DETAILED FRONTEND ARCHITECTURE (templates/ & static/)
------------------------------------------------------------------------

The user interface uses clean Jinja2 markup designed with glassmorphism aesthetics, 
responsive grids, CSS variables, and modern fonts without bloated client-side 
framework requirements.

* The Layout Shell (templates/layouts/base.html):
  Defines the responsive navigation headers, status panels, dark-mode styling variables, 
  and includes central assets:
  - static/css/theme.css (custom styling guidelines: rounded borders, translucent cards, 
    smooth transition micro-animations, glass cards)
  - static/js/site.js (global viewport events)

* AI Interview Panel (templates/interview.html & templates/practice/practice_begin.html):
  - Utilizes browser MediaRecorder API to cleanly capture and save candidate audio-visual streams.
  - Features high-fidelity WebRTC preview displays.
  - Directly feeds live webcam streams into client-side MediaPipe JS libraries to perform 
    eye-focus verification, triggering anti-cheat mechanisms instantly if eye focus is lost.

* Reporting Center (templates/report.html):
  - Beautifully translates generated backend assessment metrics into visuals.
  - Integrates Chart.js to plot sentiment flows, technical score categories, and eye focus levels.
  - Lists question-by-question breakdown, including the candidate's exact transcription, 
    AI constructive criticisms, and key expected benchmarks compared against candidate output.
